## Cleanup and side effects

- The herdr tab `w4:t1S` was closed (`herdr tab close`), which ended the Claude Code it ran; no lock or jlock
  process was left (`jlock list` empty), and the temporary folder was removed.
- Nothing was installed in the Claude Code configuration: the mod was loaded with `--plugin-dir` for that session.
  Two things the run left in the user's Claude Code data, as any session does: the trust answer for the temporary
  folder (Claude Code asked "Is this a project you created or one you trust?" and it was answered yes, for that
  folder only) and the session's transcript under `~/.claude/projects/`.

## What was found and fixed

- **A wide character made a pane line wrap.** `⛔`, `⏳` and `🔒` are two columns wide in a terminal; the view model
  measured lines in characters, so a line with a blocker took one column more than the pane. `src/i18n.ts` `width`
  now counts those emoji as two columns, and `src/view.ts` (`fit`, `lineText`) measures in columns;
  `opencode/test/view.test.ts` "a line never takes more terminal columns than the width" covers it.
- Nothing else behaved differently from the fake machine: tool registration, binding, pane opening, refresh after
  `done`, `/jtasks`, the hold through `$.process.run`, the profile's model on spawn and the guard on a subagent's
  Write all worked as the mod's tests say.
